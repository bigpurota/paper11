# What was checked

The checks cover model implementation, the timing of repayment observations, the simulated approval policy and the financial calculations. The public datasets contain observed repayments, so we can deliberately hide outcomes and test predictions against them.

| Similarity to published results | [Figure 2 on common axes](../results/simulation_fig2.png); original summaries with seed-level uncertainty in [simulation_comparison.csv](../results/simulation_comparison.csv); same metrics in [Tables 2 and 3 comparison](../results/paper_comparison.csv). |
| Known truth and placebo | Population posterior from the Gaussian mixture, calibrated and shuffled priors, equal-sized random disclosure, full-label training benchmark. |
| Training, stopping and look-ahead | A regression test flips all hidden development labels and requires identical scores, estimates and lending policies. Prosper uses first loans, maturity gaps, independent stopping and policy validation. A separate test checks the date windows. |
| Robustness | Prior odds shifts; stopping rule; borrower transfer across time; IPW and pseudo-label baselines; 4 loss scenarios; randomized audit with 2 budgets. [Full report](../results/report.md) |
| Strength of selection | An exploratory [hard-cutoff sensitivity](hard-selection.md) reruns the public experiment with deterministic acceptance on the same index, folds and seeds. [Tests](../tests/test_hard_selection.py) require complete separation on the index, tied values on one side and the closest attainable acceptance share; the reproduction compares its outputs byte for byte. |

## Repeat these checks

Use Python 3.12 and GNU Make. On macOS, XGBoost may require the OpenMP runtime (`brew install libomp`). The full run downloads about 1.14 GB of public inputs.

* `make verify` runs the regression/reference tests, then checks numerical consistency across all public result tables. This includes invariants with known answers and permits research estimates to be unfavorable.
* `make all` downloads eleven pinned input files and verifies their SHA-256 hashes. It runs the Taiwan and Prosper experiments, the simulation, the quarterly forecasts, the policy bounds, the Philippine offer study, minimax policy comparisons, the sequential audit, policy-information checks, the sequential lending model, the one-pilot break-even frontier, both SBA replays, the Bondora matched payment snapshots and the ex-ante forecast evaluation, the later-period and cross-lender pilot tests, the matched pilot-signal experiment and the dated frequency correction, the Dutch reconstruction and the Wells Fargo transfer, followed by the Dutch and Czech early-payment experiments, the hard historical cutoff and the selection-strength audit. It then generates and checks the figures and report.
* `make reproduce` writes all research results to a new temporary directory and compares against the submitted results; it reports the count that is byte-identical. The fixed graphics runtime matters for exact PNG comparisons.
* `make slides` updates the numeric fields and figures in the editable PowerPoint, then exports the presentation PDF using LibreOffice.
* The repository's [CI workflow](../.github/workflows/research.yml) tests the submitted artifacts and separately executes the pipeline from the public URLs on Linux. It compares the regenerated pilot-model, SBA, Bondora and forecast tables, with the submitted release. It checks the selection tables and lending decisions against an [independent Linux x86-64 refit](platform-refit.md) at numerical tolerance, using the same data, splits and seeds. Source data and the original Monedo borrower records are not distributed here.

## Reference run

The reference run contains 114 research outputs and passes 189 regression and reference tests. The 31-slide defense has 14 spoken slides, a clickable question index and 16 evidence slides. The separate evidence deck has 38 slides. The project pins eleven downloadable data files (1,142,957,476 bytes). [Reproduction commands](../README.md#reproduce)
