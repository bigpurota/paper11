# What was checked

The evaluation ladder in DSBA Research Seminar lecture 1 asks for presentation, independent implementation, reproduced results and research upgrades. Lecture 3, slide 41 requests an out-of-time split, AUC, a calibration plot, a logistic baseline and explicit limits. The public experiment uses both recorded repayments and deliberately generated selection. [Paper and appendix](https://arxiv.org/abs/2407.13009v1)

| Assessment item | Evidence |
|---|---|
| Algorithm fidelity | [Algorithms and estimands](algorithm.md); own implementation of B.1–B.3 and Algorithm 1; references and stress cases in [method tests](../tests/test_methods.py). |

| Policy sensitivity | Nested lending policies are compared on the same applicants. Tiny test portfolios allow exhaustive enumeration of all missing outcomes and prior endpoints. | Philippine randomized offers | Reconciled total assignments, funded accounts and currency units. Exhaustive binary examples, including intersecting rules without quotas, test the five-policy minimax calculation. A separate cutting-plane optimizer on the 20 two- and five-cutoff unrestricted and prior-count games agreed within 5 × 10⁻¹³. [Proof and references](identification.md) |
| Sequential audit | Small populations are checked against every possible reveal order. A second implementation used exact combinatorial tails and hypergeometric transitions between review points to check all 87 probability rows. The largest absolute probability discrepancy was below 5 × 10⁻¹³. [Protocol](decision-audit.md) |
| Information needed for a policy comparison | The four adjacent-band differences add up to all ten contrasts. Tests check row-space inclusion and a null-space counterexample. Aggregate binary-outcome bounds are separately compared with retrospective outcomes. [Information and policy](policy-information.md) |
| Expected value of learning | An independent exact-rational history tree checks the continuous-belief solver. Impossible observations, identical regimes and a fresh independent regime at every loan are tested. The output check reconstructs each initial funding value from the two observable branches. [Decision model](exploration.md) |
| A general break-even rule | The terminal decision calculation checks both actions under each possible signal. Independent posterior updates, including a four-state prior, check the moment formula. Tests cover a redundant public signal, complementary signals, exact ties, delayed observation and a binding lifetime ceiling. Across 816,480 grid settings the maximum direct-posterior discrepancy was below 5 × 10⁻¹⁵. Independent enumeration verifies sharp dependence bounds from the two marginal risks. [Theory](information-value.md) · [Bounds](pilot-dependence.md) |
| Chronological SBA replay | A second calculation from daily disbursement dates verified the 120 region-quarter panels. Pairwise portfolio and pilot margins are checked against the different outcome branches. [Design and timing](pilot-replay.md) |
| Can the bank target an information loan? | Reference AUC agrees with scikit-learn. Tied-score comparisons, empty outcome classes, same-quarter clustering, and the calendar barrier on past public updates are tested. Each forecast's payoff is independently recomputed from individual episode rows. The two new US source files and the two European cash snapshots are fingerprinted. The latter were linked using stable loan IDs, amount and origination date. [Targeting](pilot-targeting.md) · [US](pilot-transfer.md) · [EU](lender-pilot.md) |
| Defense | 14 main slides with a 15-minute speaking plan, including the required overfitting discussion; sixteen backup slides and editable speaker notes. [Presentation and timing](../slides/README.md). Actual delivery speed depends on the speakers. |

The [previous team project](https://github.com/bigpurota/paper15-lou-shu) used known-answer and reference tests, null controls, leakage checks, multiple specifications, sensitivity to small effects, data provenance, a clean rerun, and source-linked slides. Here the reference for rank metrics is scikit-learn on tied and weighted cases. Expected Bayesian metrics are also compared against exact enumeration. ABR integration is checked against independent numerical quadrature. Financial identities are checked at both per-applicant and per-issued-unit denominators. Key output checks read the CSVs independently of the models.

## Repeat these checks

* `make verify` runs the regression/reference tests, then checks numerical consistency across all public result tables. This includes invariants with known answers and permits research estimates to be unfavorable.
* `make all` downloads eight pinned input files and verifies their SHA-256 hashes. It runs the Taiwan and Prosper experiments, the simulation, the quarterly forecasts, the policy bounds, the Philippine offer study, minimax policy comparisons, the sequential audit, policy-information checks, the sequential lending model, the one-pilot break-even frontier, both SBA replays, the Bondora matched payment snapshots and the ex-ante forecast evaluation, then generates and checks the figures and report.
* `make reproduce` writes all research results to a new temporary directory and compares against the submitted results; it reports the count that is byte-identical. The fixed graphics runtime matters for exact PNG comparisons.
* `make slides` updates the numeric fields and figures in the editable PowerPoint, then exports the presentation PDF using LibreOffice.
* The repository's [CI workflow](../.github/workflows/research.yml) tests the submitted artifacts and separately executes the pipeline from the public URLs on Linux. It compares the regenerated pilot-model, SBA, Bondora and forecast tables with the submitted release using numerical tolerances. Source data and the original Monedo borrower records are not distributed here.

## Verified release run

On 18 November 2026 the test suite passed 108 regression and reference cases. The release uses eight source files totaling 729,853,869 bytes. An independent calculation using the cached files reproduced all 60 submitted research artifacts byte for byte. The editable PowerPoint was rebuilt from its source template and checked against the delivered PPTX and the rendered images of all 30 PDF pages. [Reproduction commands](../README.md#reproduce)
